# Гид по заданию
{: .no_toc }

Нажмите кнопку **Guide** на задании, чтобы увидеть, что взять перед рейдом.

1. TOC
{:toc}

## Что показывает

- Карту, на которой происходит задание
- Разрешённое оружие, калибры и моды
- Требуемое или запрещённое снаряжение
- Предметы для передачи или установки, с требованиями «найдено в рейде»
- Правила вроде завершения за один рейд или использования конкретных выходов

Предметы модов тоже включены.

[![Предметы для установки]({{ '/assets/images/wiki-guide-plant.png' | relative_url }})]({{ '/assets/images/wiki-guide-plant.png' | relative_url }})

Длинные списки сворачиваются до первых нескольких записей. Нажмите **+N ещё**, чтобы увидеть все.

[![Разрешённое оружие]({{ '/assets/images/wiki-guide-weapons.png' | relative_url }})]({{ '/assets/images/wiki-guide-weapons.png' | relative_url }})

## Перемещение и изменение размера

- Перетащите заголовок, чтобы переместить окно.
- Перетащите любой край, чтобы изменить размер.
- Ваша раскладка запоминается. Двойной клик по заголовку сбрасывает её.
