# QuestCodex

Браузерная вики по заданиям, которые реально загружены на вашем SPT-сервере.
{: .fs-6 }

[Начать работу](getting-started.html){: .btn .btn-primary .mr-2 }
[Скачать](https://github.com/Viper-9/QuestCodex/releases){: .btn }

Внешние вики-сайты отслеживают живой EFT — а не то, что работает на вашем сервере. QuestCodex читает таблицы заданий, которые сервер держит в памяти, и строит каталог из них. Если мод изменил условие или награду — вы увидите изменённое значение, а задания, добавленные модом, появятся в том же списке, что и ванильные, с меткой мода-источника. Мод только читает данные сервера. Он никогда не изменяет задания, профили или торговцев.
