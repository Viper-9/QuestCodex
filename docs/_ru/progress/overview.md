# Обзор
{: .no_toc }

- TOC
{:toc}

Полоса прогресса по каждому торговцу с числом завершённых и общих заданий. Торговцы, которых вы полностью прошли, становятся зелёными.

В разделе «Перейти к торговцу»:

- Готово к сдаче: все цели выполнены
- Доступно для принятия: задания, которые можно взять сейчас
- Можно передать сейчас: цели передачи, которые уже покрыты вашими предметами

Все задания сгруппированы по статусу, с поиском и той же строкой торговца, что и в вики. Задания модов несут метку своего мода. Нажмите на задание, чтобы развернуть те же детали, что и в вики (описание, гид, карта локаций, предупреждение о ветке, награды, связанные задания), плюс ваш прогресс:

- Цели показывают свои счётчики, выполненные зачёркнуты
- Заблокированные задания отмечают стартовые условия, которые вы ещё не выполнили, с вашим текущим значением
- «Открыть в вики» переходит к заданию в вики; ссылки на связанные задания переходят внутри этого списка

Каждая вкладка сортируется по тому, что вы будете искать в первую очередь:

- Активные: сначала готовые к сдаче, затем по завершённости целей
- Заблокированные: сначала ближайшие к разблокировке
- Завершённые / Проваленные: сначала самые свежие

Задания, которые вы никогда не сможете завершить на этом профиле (только для другой фракции или ветка, которую вы уже закрыли), помечаются как «Недостижимо».
