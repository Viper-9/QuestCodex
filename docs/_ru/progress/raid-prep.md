# Подготовка к рейду
{: .no_toc }

Выберите карту, которую собираетесь играть, и посмотрите всё, что хотят там ваши активные задания.

- TOC
{:toc}

## Вкладки карт

Каждая вкладка карты показывает, сколько открытых целей на ней есть.

## Задания на этой карте

Задания с целями на выбранной карте, плюс цели, которые можно выполнить на любой карте, сгруппированные по заданию. Развёртывание задания приглушает цели, относящиеся к другим картам. Сначала идут задания, нарисованные на карте, затем задания со счётчиками по прогрессу, затем остальные по названию.

## Карта

Под списками заданий находится карточка карты, которая следует за выбранной вкладкой карты и остаётся на виду при прокрутке. Это та же карта, что и [карта локаций заданий](wiki/quest-details.html#quest-locations-map) в вики, со всеми заданиями на этой карте сразу.

- Строки заданий несут тот же цветной номер, что и их маркеры. Наведите на любую сторону, чтобы подсветить другую
- Кнопки этажей, области целей и переключатель «Запертые двери» работают как в вики. Значки замков рядом с маркером говорят, какой ключ, возможно, стоит взять
- «Развернуть» открывает карту в перемещаемом окне с изменяемым размером и нумерованным списком заданий. Страница позади остаётся прокручиваемой и кликабельной. Закрыть — кнопкой закрытия или Esc

## Взять с собой / Предметы для лута

- Взять с собой: предметы для установки на этой карте, с указанием, сколько нужно и сколько у вас есть
- Предметы для лута: предметы, которые ваши задания просят найти на этой карте

## Снаряжение и особые условия

- Снаряжение · Оружие: требуемое или запрещённое снаряжение и разрешённое оружие, сгруппированные по заданию
- Особые условия: правила вроде завершения за один рейд или использования конкретного выхода

{: .note }
Цели без данных о карте берут карту, названную в их тексте, и помечаются как «из текста».
