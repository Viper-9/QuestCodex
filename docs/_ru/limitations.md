# Известные ограничения

## Моды, перехватывающие ответы в runtime

QuestCodex читает таблицы заданий, которые сервер объединил в память после завершения загрузки. Любой мод, добавляющий или изменяющий JSON заданий, отражается точно, независимо от порядка загрузки. Мод, который перехватывает маршрут вроде `/client/quest/list` и переписывает ответ при каждом запросе, никогда не касается этих таблиц, поэтому его изменения не доходят до QuestCodex. В игре вы увидите изменённое задание, а здесь — нет.

{: .warning-ru }
Если страница и игра расходятся, в первую очередь подозревайте это.

## Задания модов, добавленные из кода C#

Задания, которые мод внедряет из кода C# (`CustomQuestService.CreateQuest()`), а не из JSON-файлов, не оставляют файлового следа, поэтому их мод-источник невозможно определить. Такие задания получают общую метку мода.

## Покрытие карт заданий

- У некоторых заданий нет данных о локации, поэтому их цели не отображаются на карте.
- Задания модов показываются на карте только когда мод определяет свои зоны в данных, которые сервер может прочитать.
- QuestCodex не отслеживает, какие ключи у вас есть. Значки замков говорят, какой ключ нужен для двери, и не более.

## Только локально

SPT-сервер привязан к `127.0.0.1`, поэтому QuestCodex открывается только в браузере на машине, где запущен сервер.
